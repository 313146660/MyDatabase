# MyDatabase

一个面向眼镜店/视光工作室的客户档案 + 镜片库存管理工具，Android 原生实现，数据完全保存在本机，不依赖任何后端。

> 仓库里只有代码和虚构的演示数据，不包含任何真实客户信息。

## 功能

**客户档案**

- 16 列固定 CSV 可直接导入/导出
- 列表自动换行，可切换显示字段、按数字调字号
- 排序：最近验光 / 最近修改 / 最早验光 / 名称 A→Z / 名称 Z→A（按库记住）
- 搜索支持区间：-3.00~-1.00、1.56～1.61、2025/01~2025/12，带搜索历史
- 收藏、家庭组（同电话不同名）、字段管理、公式字段
- 详情页一键复制电话，顶部摘要卡折叠全部字段
- 验光历史：与上次对比的度数增减、首尾度数标注、等效球镜趋势图
- 客户聚合视图：列表可切换「记录 / 客户」，按电话或姓名聚合，显示累计消费与距上次配镜月数
- 复查超期标记：按用途周期（远用 18 月 / 近用 12 月 / 渐进 24 月）标红超期客户，仅标记不推送提醒
- 配镜出库留痕：详情页展示本条记录扣减的镜片型号、规格与数量，可一键跳转镜片库
- 经营看板：总记录 / 客户数 / 总营收 / 客单价 / 复购率 / 超期数，热销镜片 Top 10、用途分布、近 12 个月营收趋势

**镜片库存**

- 型号 × 球镜 × 柱镜的矩阵表格，点格子直接改库存
- 选镜片扣库存、改选自动回补；库存留空 = 未入库不提醒，0 = 缺货提醒
- 按型号、球镜范围、有无散光批量改库存，支持撤销和自定义预设
- 型号 chip 长按批量改名，低库存红色标记
- 补货清单按型号生成纯文本，一键复制或保存 .txt
- 补货目标：可设型号目标库存与度数范围目标，缺货数 = 目标 − 当前；支持按供货商分组复制/分享，货到一键入库

**数据与外观**

- 本地 JSON 备份 + WebDAV 云备份（手动/自动），恢复前自动留快照可撤销
- 深色模式、全局列表字号
- 所有数据只存在设备本地，无统计、无遥测

## 数据与隐私

- 备份格式为 JSON（version 2 / schemaVersion 2），兼容旧版。
- 首次启动生成的演示姓名、手机号均为虚构，仅用于展示家庭组和历史记录。

## 已知限制

- 没有崩溃上报、没有多设备同步，WebDAV 是唯一的内置云备份方式。
- 界面以中文为主。
