# MyDatabase

一个面向眼镜店/视光工作室的**客户档案 + 镜片库存**管理工具，Android 原生实现（Jetpack Compose），数据完全保存在本机，不依赖任何后端。

> 仓库里只有代码和虚构的演示数据，不包含任何真实客户信息。

## 功能

**客户档案**

- 16 列固定 CSV 可直接导入/导出：`姓名,电话,用途,OD,OD轴向,OS,OS轴向,瞳距,镜框,镜片,合计,时间,NO.,ADD,备注,客户`
- 列表自动换行，可切换显示字段、按数字调字号
- 记录视图排序：最近验光 / 最近修改 / 最早验光 / 名称 A→Z / 名称 Z→A（按库记住）
- 搜索支持区间：`-3.00~-1.00`、`1.56～1.61`、`2025/01~2025/12`；带搜索历史
- 收藏、家庭组（同电话不同名）、字段管理、公式字段
- 详情页一键复制电话；顶部摘要卡折叠全部字段
- 验光历史：与上次对比的度数增减、首尾度数标注、等效球镜趋势图（近视更负/远视更正都向上）

**客户聚合与经营**

- 列表可切换「记录 / 客户」：客户视图按**电话**或**姓名**聚合，组头显示累计消费、配镜次数、最近配镜日期
- 客户排序：最近配镜 / 客单价 / 累计消费 / 配镜次数 / 姓名 A→Z / 姓名 Z→A（与记录排序同一入口，自动切换）
- 复查超期：按用途周期（远用 18 月 / 近用 12 月 / 渐进 24 月）判定，超期客户标红并可一键置顶；仅做标记，不弹窗推送
- 配镜出库留痕：详情页展示本条记录扣减的镜片型号 / 规格 / 数量与当前库存，点击可跳到镜片库对应条目
- 经营看板：总记录、客户数、总营收、客单价、本月新增、复购率、超期客户数；热销镜片 Top 10、用途分布、近 12 个月营收趋势
- 视图偏好（记录/客户、聚合方式、超期置顶、排序）按库保存，重启后保留

**镜片库存**

- 型号 × 球镜 × 柱镜的矩阵表格，点格子直接改库存
- 选镜片扣库存、改选自动回补；库存留空 = 未入库不提醒，`0` = 缺货提醒
- 按型号/球镜范围/有无散光批量改库存，支持撤销和自定义预设
- 型号 chip 长按批量改名；低库存红色标记
- 补货清单按型号生成纯文本（单光 4 片、带散光 2 片，数量可改），一键复制或保存 `.txt`
- 补货目标：可设型号目标库存与度数范围目标，缺货数 = 目标 − 当前；支持按供货商分组复制/分享，货到一键入库，并保留补货历史

**数据与外观**

- 本地 JSON 备份 + WebDAV 云备份（手动/自动），恢复前自动留快照可撤销
- 深色模式、全局列表字号
- 指纹解锁：开启后冷启动或离开超过 30 秒返回时验证指纹（Android 9+，只调用系统验证，不读取指纹数据）
- 解锁密码：可另设 4 位以上密码作为兜底，指纹失效或失败时可输入密码进入；只保存 `salt:SHA-256` 摘要，不存明文
- 大库性能：冷启动异步加载、派生结果缓存、搜索防抖，上千条客户记录也能秒开
- 所有数据只存在设备本地（SharedPreferences / `localStorage`），无统计、无遥测

## Android 构建

环境：JDK 17、Android SDK 34、Gradle 8.7（仓库带 `gradlew`，也可用本机 Gradle 8.7）。

```bash
cd android
./gradlew :app:assembleDebug       # Windows: gradlew.bat :app:assembleDebug
```

产物：`android/app/build/outputs/apk/debug/MyDB-<versionName>.apk`（如 `MyDB-2.33.apk`）。

首次构建前在 `android/local.properties` 写 SDK 路径（该文件已被 `.gitignore` 忽略）：

```properties
sdk.dir=/path/to/Android/Sdk
```

`minSdk 26`、`targetSdk 34`，使用 debug 签名；正式发布请自行配置 release keystore。

## 数据与隐私

- **不要提交**：真实备份 JSON、`客户.csv`、`local.properties`、签名文件。`.gitignore` 已覆盖常见情况。
- 备份格式为 JSON，`version: 2 / schemaVersion: 2`，同时兼容旧版 v1 与裸 state。
- App 首次启动生成的演示姓名、手机号均为虚构（如 陈晓明 / `138000000xx`），仅用于展示家庭组和历史记录。
- 指纹解锁仅调用系统 BiometricPrompt，App 不读取、不存储任何生物特征数据。
- 解锁密码只保存加盐 SHA-256 摘要，不保存明文；密码遗失无法找回，请妥善保管。

## 已知限制

- 没有崩溃上报、没有多设备同步；WebDAV 是唯一的内置云备份方式。
- 指纹解锁需要 Android 9+ 且设备已录入指纹；更低版本可在设置中看到但不生效。
- UI 以中文为主，代码注释为中文。
