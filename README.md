# MyDatabase

一个面向眼镜店/视光工作室的**客户档案 + 镜片库存**管理工具，Android 原生实现（Jetpack Compose），数据完全保存在本机，不依赖任何后端。

> 仓库里只有代码和虚构的演示数据，不包含任何真实客户信息。

## 功能

**客户档案**

- 16 列固定 CSV 可直接导入/导出：`姓名,电话,用途,OD,OD轴向,OS,OS轴向,瞳距,镜框,镜片,合计,时间,NO.,ADD,备注,客户`；任意库都可从右上角菜单导入 / 导出 CSV
- 列表自动换行，可切换显示字段、按数字调字号；显示字段为空时不占位
- 排序：最近配镜 / 累计消费 / 客单价 / 配镜次数，支持升序与降序（记录与客户视图共用一套，按库记住）
- 搜索支持区间：`-3.00~-1.00`、`1.56～1.61`、`2025/01~2025/12`；搜索历史在点进搜索框时出现，不常驻
- 收藏、家庭组（同电话不同名）、字段管理、公式字段
- 详情页一键复制电话；顶部摘要卡折叠全部字段
- 验光历史：与上次对比的度数增减、首尾度数标注、等效球镜趋势图（近视更负/远视更正都向上）

**客户聚合与经营**

- 列表可切换「记录 / 客户」：客户视图按**电话**或**姓名**聚合，组头显示累计消费、配镜次数、最近配镜日期
- 视图切换、聚合方式、超期置顶与排序统一收进右上角菜单，排序/聚合为二级菜单，入口直接显示当前状态
- 复查超期：按用途周期（远用 18 月 / 近用 12 月 / 渐进 24 月）判定，超期客户标红并可一键置顶；复查提醒只做标记，不弹通知
- 配镜出库留痕：详情页展示本条记录扣减的镜片型号 / 规格 / 数量与当前库存，点击可跳到镜片库对应条目
- 经营看板（客户库）：总记录、客户数、总营收、客单价、本月新增、复购率、超期客户数；热销镜片 Top 10、用途分布、近 12 个月营收趋势
- 通用统计（其他库）：总记录、本月新增、收藏、字段数、近 12 个月新增趋势，并自动统计所有单选 / 多选字段的取值分布
- 视图偏好（记录/客户、聚合方式、超期置顶、排序）按库保存，重启后保留

**字段与待办**

- 15 种字段类型：文本、长文本、数字、进度、电话、日期、提醒、单选、多选、是/否、关联选择、自动编号、创建时间、更新时间、公式
- 关联选择：可从关联库（如镜片库）挑选，也可手动输入任意文本；手动内容不关联库存
- 类型选择改为**分组网格弹层**（基础 / 选项 / 高级），不再是长下拉列表
- 字段名称可留空，自动使用类型名（如「提醒」），重名自动加序号
- 日期字段调用系统日历；提醒字段可选日期 + 时间，按系统闹钟级优先级登记，锁屏 / 待机也能准时唤醒，开机后自动重排
- 提醒设置：系统铃声或静音、震动开关、响铃与震动时长，并提供「测试提醒」5 秒验证
- 快捷预设：编辑记录时的三个提醒快捷键可自定义类型（几小时后 / 今天某时 / 明天某时）与时间；名称默认跟随时间自动生成，手动填写后才固定，可恢复默认
- 提醒可反复使用：响过之后清除再设新时间会再次提醒；每条记录的每个提醒字段独立计时
- 进度字段用滑块编辑，带 0/25/50/75/100% 快捷值，列表与详情显示百分比
- 新建 To-Do 库的推荐配法：任务名称（文本）、状态（单选）、优先级（单选）、截止日期（日期）、已完成（是/否）、进度（进度）、标签（多选）、提醒（提醒）、备注（长文本）

**镜片库存**

- 型号 × 球镜 × 柱镜的矩阵表格，点格子直接改库存
- 选镜片扣库存、改选自动回补；库存留空 = 未入库不提醒，`0` = 缺货提醒
- 按型号/球镜范围/有无散光批量改库存，支持撤销和自定义预设
- 型号 chip 长按批量改名；低库存红色标记
- 补货清单按型号生成纯文本（单光 4 片、带散光 2 片，数量可改），一键复制或保存 `.txt`
- 补货目标：可设型号目标库存与度数范围目标，缺货数 = 目标 − 当前；支持按供货商分组复制/分享，货到一键入库，并保留补货历史
- 补货清单可用 − / + 逐个调整本次补货数量（点数字恢复默认，调到 0 表示本次不补），合计与生成的文本会同步更新
- 右上角菜单：库存提醒规则、补货清单、CSV 导入 / 导出，以及编辑库、字段管理、列表显示字段

**数据与外观**

- 本地 JSON 备份 + WebDAV 云备份（手动/自动），恢复前自动留快照可撤销
- 深色模式、全局列表字号
- 指纹解锁：开启后冷启动或离开超过 30 秒返回时验证指纹（Android 9+，只调用系统验证，不读取指纹数据）
- 解锁密码：可另设 4 位以上密码作为兜底，指纹失效或失败时可输入密码进入；只保存 `salt:SHA-256` 摘要，不存明文
- 提醒通知：Android 13+ 首次启动申请通知权限；可自定义铃声（系统铃声 / 静音）、震动开关、响铃与震动时长，并在「我的 → 提醒」查看通知权限、精确闹钟与后台运行状态
- 大库性能：冷启动异步加载、派生结果缓存、搜索防抖，上千条客户记录也能秒开
- 所有数据只存在设备本地（SharedPreferences），无统计、无遥测

## Android 构建

环境：JDK 17、Android SDK 34、Gradle 8.7（仓库带 `gradlew`，也可用本机 Gradle 8.7）。

```bash
cd android
./gradlew :app:assembleDebug       # Windows: gradlew.bat :app:assembleDebug
```

产物：`android/app/build/outputs/apk/debug/MyDB-<versionName>.apk`（如 `MyDB-2.51.apk`）。

首次构建前在 `android/local.properties` 写 SDK 路径（该文件已被 `.gitignore` 忽略）：

```properties
sdk.dir=/path/to/Android/Sdk
```

`minSdk 26`、`targetSdk 34`，使用 debug 签名；正式发布请自行配置 release keystore。

## 数据与隐私

- **不要提交**：真实备份 JSON、`客户.csv`、`local.properties`、签名文件。`.gitignore` 已覆盖常见情况。
- 备份格式为 JSON，`version: 2 / schemaVersion: 2`，同时兼容旧版 v1 与裸 state。
- App 首次启动生成的演示姓名、手机号均为虚构（如 陈晓明 / `138000000xx`），仅用于展示家庭组和历史记录。
- 指纹解锁仅调用系统 BiometricPrompt，App 不读取、不存储任何生物特征数据。
- 解锁密码只保存加盐 SHA-256 摘要，不保存明文；密码遗失无法找回，请妥善保管。

## 已知限制

- 没有崩溃上报、没有多设备同步；WebDAV 是唯一的内置云备份方式。
- 指纹解锁需要 Android 9+ 且设备已录入指纹；更低版本可在设置中看到但不生效。
- 提醒通知需要通知权限；未允许时可在「我的 → 提醒」里一键前往开启。系统未允许精确闹钟时提醒可能延迟几分钟，同一界面可直接跳转允许。
- 后台提醒还需要「忽略电池优化」；小米 / 华为等系统必须在系统设置中额外允许本应用的「自启动」与「后台弹出界面」，否则锁屏或切到后台后提醒可能被系统拦截。可在「我的 → 提醒」查看状态并跳转设置。
- UI 以中文为主，代码注释为中文。
