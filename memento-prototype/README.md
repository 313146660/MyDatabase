# 网页原型

用于先敲定 UI 与交互、再 1:1 移植到 Android 的可点击原型。**零依赖、零构建**：三个文件，双击 `index.html` 就能跑。

- 画布：390 × 844 手机模拟框
- 数据：`localStorage`，不联网（WebDAV 备份除外）
- 首次启动写入 5 个演示库，客户姓名/电话均为虚构数据
- 底部 tab：首页 / 我的

## 运行

```
memento-prototype/
├─ index.html    入口
├─ app.js        全部逻辑（无框架）
└─ styles.css    设计系统与布局
```

直接双击 `index.html`，或用任意静态服务器打开。没有 npm、没有打包、没有外部 CDN。

换浏览器、清理站点数据会清空 `localStorage`。重要数据先到「我的 → 备份与恢复」导出 JSON。

## 数据模型

```js
{
  id: 'lib_customer',
  name: '客户库',
  fields: [{ id: 'c_name', name: '姓名', type: 'text' }, ...],
  entries: [
    {
      id: 'e_xxx',
      favorite: 0,
      createdAt: 0,
      updatedAt: 0,
      values: { c_name: '张三', c_phone: '13800000000', c_od: '-1.00ds/-0.50dc' }
    }
  ]
}
```

- 所有字段值都以字符串存在 `values` 里。
- 镜片等关联字段只存文字快照，不存条目 id；删除镜片库不会影响客户数据。
- 备份格式与应用端一致（JSON，`version: 2`，兼容 v1）。

## 已实现的主要交互

- 客户列表：搜索、收藏、家庭组、字段名开关、数字字号、排序、搜索历史
- 客户详情：折叠全部字段、复制电话、验光历史（相邻两次增减 + 首尾趋势）
- 镜片表格：矩阵透视、点格子改库存、批量改库存（撤销/预设）、型号长按改名
- 库存提醒：统一阈值 + 规则、首页低库存、矩阵红框
- 补货清单：按型号生成纯文本，复制或保存 `.txt`
- CSV 导入/导出、字段管理、公式字段、本地/WebDAV 备份、深色模式

## 注意

`localStorage` 里的数据不在仓库中，也不会被提交。截图或调试时请先把真实客户数据替换成演示数据。
